# AE2 BatchCraft

**让一套处理样板，轻松驱动一组并行机器。**

Minecraft 1.21.1 | NeoForge | Applied Energistics 2

[English](README.md) | **简体中文**

## 它能做什么？

AE2 BatchCraft 为 Applied Energistics 2 加入了一个 **一对多的处理样板 P2P 网络**。

样板 P2P 输入端从原版 AE2 样板供应器接收完整合成任务，再以轮询方式分配给多个输出端或样板 P2P
单元。扩建产线时，只需增加端点和机器，无需复制样板，也不需要为每台机器额外占用 AE 频道。

## 模组内容

| 物品 / 功能               | 用途                                                                                                 |
|---------------------------|------------------------------------------------------------------------------------------------------|
| **样板 P2P 通道（输入）** | 连接样板供应器，接收并分配处理任务，同时收集返回产物；占用 `1` 个 AE 频道。                          |
| **样板 P2P 通道（输出）** | 将材料送入一台相邻机器并返回产物；不占用 AE 频道，最多可排队 `64` 个任务。                           |
| **样板 P2P 通道（能量）** | 优先为 AE 子网供能，再把剩余 FE 分配给输出端机器和活跃单元的能量端口；无需频道和 P2P 频率。          |
| **样板P2P单元（管理）**   | 接收一个完整任务，并协调一组已绑定的功能端口；提供福鲁伊克斯原色和全部 `16` 种 AE2 线缆颜色。        |
| **样板 P2P 单元端口**     | 包含传输、掉落、放置、返回、提取、拾取、破坏、红石和能量九种端口；管理器和端口均不额外占用频道。     |
| **产物提取卡**            | 让样板供应器主动从相邻机器提取经过筛选的产物；支持物品、流体及兼容模组提供的资源类型。               |
| **AE部件放置器**          | 在最大 `16 x 16` 的点、线或平面范围内批量放置 AE 线缆与线缆部件，并可统一写入 P2P 频率。             |
| **按材料配置**            | 为普通输出指定材料输入面，或为样板 P2P 单元端口选择普通、掉落、放置三种输出形式。                    |

## 为什么使用它？

- **并行加工：**完整任务在可用机器之间轮询分配，充分利用整条产线。
- **节省频道：**只有样板 P2P 输入端占用 `1` 个频道；输出端、单元管理器和单元端口均不占频道。
- **集中管理样板：**处理样板仍放在一个原版样板供应器中，无需为每台机器准备一套样板。
- **灵活自动化：**一个样板 P2P 单元可以完成材料传输、方块放置与破坏、掉落物收集、产物返回、红石输出和 FE 供应。
- **自动提取产物：**样板供应器、P2P 输出端和单元提取端口均可主动从机器中取回结果，减少额外产物管道。
- **集中供能：**能量通道可按均分或轮询方式为符合条件的机器供应 FE。
- **快速扩建：**AE部件放置器可以一次铺设整排或整面的线缆与端点。
- **兼容多类资源：**通用 AE 资源处理支持物品、流体，以及安装 Applied Mekanistics 后的化学品等兼容类型。

## 快速上手

### 搭建并行机器组

1. 将处理样板放入主网中的原版 AE2 **样板供应器**。
2. 在 AE 子网线缆上安装 **样板 P2P 通道（输入）**，让它的正面贴住样板供应器的输出面。
3. 在同一子网中为每台加工机器安装一个 **样板 P2P 通道（输出）**，并让输出端正面朝向机器。
4. 使用 AE2 记忆卡 `Shift + 右击` 输入端，生成并保存频率。
5. 使用同一张记忆卡右击所有输出端，写入相同频率。
6. 发起合成任务；输入端会把每个完整任务发送给下一个可用输出端。

输入端与全部端点必须位于同一个 AE 子网，且所在区块必须保持加载。频率 `0000` 代表尚未配置。离线、未加载、忙碌或无法接收材料的端点会被跳过。

> 单个任务不会拆分给多台机器。例如，一次完整的 `10000 A -> 10000 B` 任务只会发送给一个端点。

### 搭建样板 P2P 单元

当处理流程需要多个接口或世界交互，而不是单一机器输入面时，可以使用样板 P2P 单元。

1. 将**样板P2P单元（管理）**作为线缆中心安装在子网中。
2. 用记忆卡把样板 P2P 输入端的频率写入管理器。
3. 使用记忆卡 `Shift + 右击` 管理器，保存该管理器的身份。
4. 使用同一张记忆卡右击每个功能端口，将端口绑定到该管理器。
5. 在处理样板编码界面中，将鼠标悬停在输入材料上并按 `Ctrl + 鼠标中键`，选择普通、掉落或放置输出。

管理器会与普通输出端一起参与轮询，但一次只处理一个任务。它的端口必须位于同一个 AE 子网，并保持绑定到该管理器的身份。

### 可选自动化

- 在样板 P2P 输入端的**产物返回配置**中设置提取参数；开关只控制同频率普通输出端，间隔和数量也会同步给单元提取端口。关闭单元管理器的“同步主端配置”后，可在管理器中单独调整这两个参数。
- 将**产物提取卡**安装到样板供应器的升级槽，用于配置样板供应器自身的相邻机器提取与返回过滤。
- 将**样板 P2P 通道（能量）**朝向 FE 来源安装，为子网和符合条件的机器供能；右击可选择被动/主动输入及均分/轮询方式。
- 使用 **AE部件放置器**选择点、线或平面，设置线缆、部件和可选的记忆卡频率，即可一次放置全部端点。

## 游戏内指南

安装 [GuideME](https://modrinth.com/mod/guideme) 后，将鼠标悬停在本模组任意物品上并按 AE2 指南键 `G`
。中英文指南包含配方、完整搭建步骤、单元端口行为、产物返回模式、能量设置以及重要的任务重置警告。
