# AE2 批量工艺

<Row gap="16">
  <ItemImage id="ae2_batchcraft:pattern_p2p_tunnel_input" scale="3" />
  <ItemImage id="ae2_batchcraft:pattern_p2p_tunnel_output" scale="3" />
  <ItemImage id="ae2_batchcraft:pattern_p2p_tunnel_energy" scale="3" />
  <ItemImage id="ae2_batchcraft:component_placer" scale="3" />
</Row>

AE2 BatchCraft 为 AE2 的处理样板提供一对多 P2P 分发通道。

- 原版样板供应器仍负责保存样板和接入主网。
- 样板 P2P 通道输入端接收它发出的合成任务，再把任务轮询分配给同一频率下的多个输出端。
- 每个从端可以连接一台机器，从端会按照样板声明的材料输入面向机器提供材料，并把产物返回给样板供应器。

在任意物品栏中把鼠标移到本模组的输入端、输出端、能量通道或放置器上，按住 AE2 的指南按键 `G`，都可以重新打开本页面。

<br/>

## 加入的功能/物品

- 样板 P2P 通道（输入）：接收原版样板供应器的任务并分发给同频率下的输出端。
- 样板 P2P 通道（输出）：接收输入端分发的任务并向机器输入材料，同时接收机器产物并返回输入端。
- 样板 P2P 通道（能量）：优先为所在 AE 子网供电，再把剩余 FE 平均提供给该子网中所有已配置输出端连接的机器。
- AE部件放置器：使用 AE 网络库存或九个本地材料槽，在选定的点、线或面内批量放置线缆和线缆部件。
- 样板编码可设置材料输入面：在原版 AE2 样板编码终端中切换到“处理样板”，把鼠标移到某个输入材料上并按住 `Ctrl + 鼠标中键`，即可打开材料输入面设置。需要注意的是，方向信息只会被样板 P2P 通道输出端执行，原版样板供应器会忽略这些额外信息。

<br/>

## 值得注意

- 样板 P2P 通道输入端/输出端必须位于同一个 AE2 子网中，并且所在区块已加载。
- 频率 `0000` 表示端点尚未配置。未配置频率时，主端/从端不会工作。
- 能量通道自身没有频率。它会为当前 AE 子网中所有频率不为 `0000` 的输出端供电，不区分这些输出端使用的具体频率。
- 通道只传递合成任务和返回产物，不会传递普通网络存储或频道。
- 大型任务不会拆分。例如 `10000 A -> 10000 B` 由一台机器接收完整输入，不会按数量拆成多个小任务。
- 严格模式只验证返回物品的类型，不验证机器配方是否真正完成。共用机器时应避免其他流程提前产生与主要产物同类型的物品。

<br/>

## 物品对比

|          | 样板 P2P 通道（输入）         | 样板 P2P 通道（输出） |
|----------|------------------------------| --- |
| I/O      | 输入端                       | 输出端 |
| AE 频道  | 占用 `1` 个                  | 不占用 |
| 连接对象 | 原版样板供应器输出面         | 加工机器 |
| 主要职责 | 接收并分配任务、汇总返回产物 | 向机器输入材料、接收机器产物 |
| 频率配置 | 生成并写入记忆卡             | 从记忆卡读取主端频率 |
| 返回模式 | 同频率的全局配置             | 可同步主端或使用本地配置 |

<br/>

## 样板 P2P 通道（输入）

<RecipeFor id="ae2_batchcraft:pattern_p2p_tunnel_input" />

主端是这组 P2P 通道唯一的任务入口。它必须安装在 AE 子网线缆上，并朝向主网中原版样板供应器的输出面。主端会被原版样板供应器识别为加工机器。

### 配置

- P2P 频率：使用 AE2 记忆卡 `Shift + 右击` 主端，为它生成频率并写入记忆卡。再用该记忆卡右击从端。
- 产物返回模式：空手右击主端打开配置界面。这里的选择会同步到同频率下所有启用了“同步主端配置”的从端。

### 分配规则

主端从上一次成功接收任务的从端之后继续轮询。离线、区块未加载、存在待补发材料、严格批次正在执行不同样板或已达到 `64` 个任务上限的从端，不会参与本次分配。

如果某个从端完全无法接收材料，主端会尝试下一个从端。如果已经有材料成功进入机器，任务不会再改派，以免同一次合成被拆到多台机器。

<br/>

## 样板 P2P 通道（输出）

<RecipeFor id="ae2_batchcraft:pattern_p2p_tunnel_output" />

从端是任务出口和产物入口。安装时让从端正面朝向机器；没有为材料指定输入方向时，材料只从从端与机器的连接面输入。

从端不占用 AE 频道，但必须与主端位于同一个子网 AE 网格、使用相同的非零 P2P 频率，并且所在区块已加载。

### 配置

空手右击从端打开配置界面。

- 同步主端配置：开启后，从端持续采用主端的产物返回模式。界面会显示当前同步到的模式，但不能在从端修改。
- 本地产物返回模式：关闭同步后，可以只为当前从端选择返回模式，不影响主端或其他从端。

正在执行的严格批次会继续使用接收首个任务时的规则；配置变化用于后续批次。

<br/>

## 产物返回模式

| 行为 | 无阻挡 | 严格 |
| --- | --- | --- |
| 没有活动合成任务 | 放行全部产物 | 放行全部产物 |
| 有活动合成任务 | 放行全部产物 | 只放行当前批次样板声明的产物和副产物类型 |
| 返回数量 | 不限制 | 不限制 |
| 同样板并发批次 | 不等待产物，不建立严格批次 | 最多累计 `64` 个相同样板任务 |
| 不同样板任务 | 可继续尝试接收 | 等待当前批次完成 |
| 适用场景 | 机器产物完全隔离、优先吞吐量 | 多种产物共用返回路径、需要避免串货 |

### 无阻挡

无阻挡模式不根据合成任务过滤返回内容，也不等待任务产物返回。它的限制最少，适合每台机器或每条输出管线已经保证不会混入无关产物的场景。

### 严格

严格模式在存在活动批次时建立产物类型白名单。白名单来自处理样板声明的全部输出，因此主要产物和副产物都能从任意机器输出槽分别返回。

严格模式不限制单次返回数量。例如样板声明产出 `3 A`，机器一次返回 `8 A` 时，`8 A` 都会通过。批次结束只使用累计返回的主要产物数量作为完成信号；副产物不会消耗额度或提前结束批次。

当累计主要产物达到当前同样板批次的需求后，批次结束并允许接收不同样板。没有活动批次时，严格模式不会阻挡机器中已有的其他产物。

<br/>

## 样板编码设置合成材料的输入方向

在原版 AE2 样板编码终端中切换到“处理样板”，把鼠标移到某个输入材料上并按住 `Ctrl + 鼠标中键`，即可打开材料输入面设置。

- 自动方向：只使用机器与样板 P2P 通道输出端的连接面。
- 东面、南面、西面、北面、顶面、底面：使用世界绝对方向，只尝试指定面，不回退到连接面。
- 左/右提示：方向界面会根据打开 GUI 时玩家的朝向，在两个水平方向旁标注相对玩家的左和右。转身不会改变本次界面的标注。

方向信息存储在处理样板中，但只有样板 P2P 通道输出端会执行。带有方向信息的样板仍可放入原版样板供应器并正常使用；原版样板供应器会忽略这些额外信息。缺失、非法或无法读取的方向信息按自动方向处理。

<br/>

## 样板 P2P 通道（能量）

<RecipeFor id="ae2_batchcraft:pattern_p2p_tunnel_energy" />

将能量通道安装到 AE 子网线缆上，并让正面朝向 FE 能源方块。它不占用 AE 频道、不保存 P2P 频率，也不会与内存卡或合成任务交互。

空手右击能量通道可以打开配置界面。默认模式为被动接收，只接受外部方块主动推送的 FE。主动拉取模式仍然接受 Push，并会从正面能源方块 Pull；当仍有电力缺口且能源方块还有能量时，拉取间隔会从 5 Tick 逐步缩短到 1 Tick。

两种模式都允许外部方块主动向能量通道输入 FE。主动模式从每 5 Tick 拉取一次开始，只有当前 AE 子网或输出端机器仍然缺电并且能源方块还能继续供电时才会加速。能量通道自身没有能量缓存。

接收到的能量按以下顺序提供：

1. 能量通道所在的 AE 子网。
2. 同一 AE 子网中所有频率不为 `0000` 的样板 P2P 通道输出端正面连接的机器。

所有符合条件的从端都会参与供电，不区分具体频率。能量会尽量平均分配；某台机器拒绝的份额会继续提供给其他机器。位于其他 AE 网格、区块未加载或频率为 `0000` 的从端不会参与。

<br/>

## AE部件放置器

<RecipeFor id="ae2_batchcraft:component_placer" />

放置器沿用 AE2 无线终端的网络绑定、无线范围和耗电规则。使用网络材料前，需要先通过 AE2 安全终端绑定网络并为放置器充电。与网络断开时，仍可使用九个本地材料槽中的物品。

### 选择范围

- `Shift + 右击`方块设置第一个点，再右击对角位置完成选择。
- 开始选择新范围时，偏移会重置为 `X: 0、Y: +1、Z: 0`，默认在所选方块上方一格放置。
- 只能选择一个点、一条线或一个面，不允许选择立体区域。
- 每个轴最多包含 `16` 格，一个面最多包含 `16x16` 个目标。
- 放置器界面的 X、Y、Z 控件可将整个范围沿对应轴平移最多 `16` 格，不会改变范围大小。

### 配置与放置

- 将线缆放入“线缆标记”槽。该槽是幽灵槽，只记录线缆的精确类型和颜色，不会消耗样品；不能选择致密线缆。
- 将可附着在线缆上的部件放入“部件标记”槽。两个标记槽都是幽灵槽，不会消耗样品。
- 放置器界面会显示玩家背包，可根据需要把线缆或部件放入九个本地材料槽。
- 设置所有标记部件朝向的世界绝对方向。
- 左击四色频率方块可将频率重置为 `0000`。将 AE2 记忆卡拿在光标、主手或副手中，右击该方块可加载卡中保存的 P2P 通道频率。
- 九个本地材料槽允许放入可用的 AE 线缆和可附着在线缆上的部件。
- 点击“放置”开始工作。目标位置不是空气时，会在扣减任何材料前直接跳过。
- 每个目标都会先从 AE 网络扣减所选线缆和部件，网络无法扣减时再使用九个本地槽。任一物品不足时跳过该目标，并退回已经扣减的物品。
- 每个新放置的 P2P 部件都会立即写入放置器当前显示的频率；频率为 `0000` 时 P2P 部件保持未配置状态，非 P2P 部件忽略频率。
