# AE2 BatchCraft

<p align="center">
  <strong>让一套处理样板，轻松驱动一组并行机器。</strong>
</p>

<p align="center">
  Minecraft 1.21.1 · NeoForge · Applied Energistics 2
</p>

## 它能做什么？

AE2 BatchCraft 为 AE2 加入了**一对多的处理样板 P2P 网络**。

合成任务会由输入端自动、均匀地分配给多个输出端，让多台机器共同处理同一套样板。扩建产线时，只需增加输出端和机器，不必复制样板，也不会额外占用 AE 频道。

## 新增内容

| 物品 / 功能 | 用途 |
| --- | --- |
| **样板 P2P 通道（输入）** | 连接原版样板供应器，接收并分配合成任务；占用 `1` 个 AE 频道 |
| **样板 P2P 通道（输出）** | 将任务送入加工机器并回收产物；**不占用 AE 频道** |
| **样板 P2P 通道（能量）** | 为所在子网和输出端连接的机器统一、均衡地供应 FE |
| **无线样板P2P放置器** | 批量放置线缆与输入端 / 输出端，支持点、线和最大 `16 × 16` 的平面 |
| **材料输入面配置** | 为处理样板中的每种材料指定机器输入面，轻松适配多面输入配方 |

## 为什么使用它？

- **并行加工**：任务在可用机器之间轮询分配，充分利用整条产线。
- **节省频道**：一组输出端只有输入端占用 `1` 个频道，输出端均不占频道。
- **集中管理**：样板仍放在原版样板供应器中，无需为每台机器准备一套样板。
- **灵活回收**：提供无阻挡与严格两种产物返回模式，可按产线需求选择。
- **快速扩建**：无线放置器可直接从 AE 网络取用材料，批量铺设整排或整面设备接口。
- **兼容化学品**：安装 Applied Mekanistics 后，可传输 Mekanism 化学品。

## 快速上手

1. 将处理样板放入原版 AE2 **样板供应器**。
2. 在供应器输出面安装**样板 P2P 通道（输入）**。
3. 用 AE2 记忆卡 `Shift + 右击` 输入端，生成并保存频率。
4. 在各台加工机器前安装**样板 P2P 通道（输出）**，再用记忆卡右击绑定同一频率。
5. 发起合成任务，输入端便会自动把任务分配给可用机器。

> 输入端与输出端需要连接在同一个 AE 网络中。每个输出端对应一台加工机器。
